# 前端记忆

本文件记录 Web 与小程序当前页面、交互、请求和权限事实。

## Web 工作空间与组件

- `apps/web` 包含平台端 `/platform/*` 和租户端 `/tenant/*` 两个工作空间。
- 平台端包含首页、租户、图片、员工、角色、菜单、部门、基础设置、微信小程序配置、
  字典、用户、系统日志、操作日志、登录日志和个人信息页面。
- 租户端包含首页、图片、员工、角色、只读菜单、部门、基础设置、用户、操作日志、登录
  日志和个人信息页面。
- 组件按 `base`、`composite`、`domain` 分组；管理表格复用 `SearchTable`，配置式表单
  复用 `SchemaForm`，租户、部门、角色、员工和日志操作者使用具名可搜索选择器。
- Ant Design 全局组件尺寸由 `antdConfig.componentSize` 控制，当前默认 `small`。
- 平台和租户工作空间使用按员工、工作空间与租户隔离的标签栏；个人信息不进入数据库
  菜单，但可以加入标签栏。

## 管理能力

- 员工支持搜索、分页、新增、编辑、分配角色、重置密码、启停，以及删除已停用且无引用
  的普通员工。
- 角色支持新增、编辑、权限配置、启停和无员工关联时删除；普通管理员只能操作自身权限
  子集。
- 部门支持树形新增、编辑和空部门删除；平台统一维护平台与租户菜单，租户菜单页只读。
- 平台租户管理支持新增、编辑、启停、所有者改密、小程序码、进入租户和删除空停用租户。
- 图片库支持来源、分类、搜索、分页、上传、预览、重命名、改分类、删除和批量管理。
- 平台基础设置、租户基础设置和微信小程序配置按查看/编辑权限分别控制进入与保存。
- 平台用户可以查看全部租户归属；平台与租户分别控制用户全局状态和租户归属状态。
- 平台和租户日志页面按权限及可信租户范围查询系统、操作和登录记录。

## 登录、请求与权限

- 登录页使用真实账号、密码和验证码，不保存演示账号。
- Web 只保存 `accessToken` 和 `expiresAt`；保持登录使用 `localStorage`，否则使用
  `sessionStorage`。401 或会话恢复失败时统一清理登录态。
- 公开请求和受保护请求分别使用 `requestJSON`、`requestAdminJSON`；受保护请求自动
  注入 Bearer Token，并统一解析 `{code,message,data}`。
- 请求和上传错误读取 `X-Request-ID`；服务端业务文案优先，网络和非法响应使用本地
  兜底文案。
- `/me` 返回实时角色、权限、菜单和品牌。页面由 `view` 权限和工作空间守卫控制，按钮
  使用 `Permission`；无权限进入 403，未知静态路由进入 404。
- 平台代管会话保留真实平台员工身份；无可访问租户页面时可以恢复平台会话。
- 个人资料只允许本人修改手机号和头像；修改密码成功后清理全部本地认证信息并重新登录。

## 微信小程序

- 当前小程序是单页租户登录 Demo，通过页面 `scene` 读取十进制租户 ID。
- 首次只有 scene、没有 Token 时等待用户主动登录；手机号和头像授权均可跳过。
- 客户端持久化 Token 与最后租户 scene；401 保留 scene 并尝试重新登录，网络错误不清理
  原会话。
- 已登录用户进入其他租户时，目标租户登录成功后才替换原会话。
- 头像使用 `chooseAvatar`，压缩为 512×512、质量 80，并在读取成功且不超过 5MB 后上传；
  压缩或读取失败时不上传原图。

## 验证约定

- Web 使用 ESLint、Stylelint、TypeScript 和 Vitest；小程序使用 ESLint、Stylelint、
  TypeScript 和 Vitest。
- Web 重点覆盖 Query 与关键响应；小程序覆盖 scene、Storage、Request ID、登录、恢复、
  401 自愈、跨租户切换和竞态。
- 页面运行验证优先复用用户维护的 `http://localhost:10001`，不得擅自重复启动或替换
  该进程；本地 Web `/api` 缺省代理到本机 Go 服务 `http://127.0.0.1:8080`，并可由
  `VITE_API_PROXY_TARGET` 覆盖。
- 小程序开发环境 API 由 `.env.development` 配置；仓库示例域名不能直接用于联调。
